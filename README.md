# Mora TV

Reproductor IPTV nativo para Android y Android TV. Login Xtream Codes o enlace M3U,
lista de canales, películas, series, favoritos, búsqueda, vista previa con pantalla
completa y ventana flotante (Picture-in-Picture).

Reproductor de propósito general: el usuario configura su propio servidor. La app no
incluye ni distribuye contenido.

## Tecnología
Kotlin · Jetpack Compose · Media3/ExoPlayer · Retrofit · almacenamiento cifrado.

## Compilar
```
./gradlew assembleDebug
```

## Actualizaciones
La app comprueba GitHub Releases al abrirse y avisa si hay una versión más reciente.
